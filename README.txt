WiFi Lobby (Godot 4.2+, GL Compatibility)
=========================================
Запуск: откройте project.godot в Godot 4 и нажмите Play. Для проверки сети нужны два устройства
(или ПК + телефон) в одной Wi-Fi сети.

Что есть в лобби
- Слева сверху: "В сети" / "Нет подключения к сети" и ник игрока (нажмите на ник, чтобы изменить).
  Первый ник = название модели телефона (на ПК - имя пользователя системы).
- По центру: low-poly модель игрока, ник под ней, деньги над ней (старт 25.000 $).
  Свайп/мышь по свободному месту поворачивает вашего персонажа.
- Справа снизу: [Магазин] [Инвентарь]. В инвентаре слева "Снаряжение" (идёт в игру),
  справа "Инвентарь" (АК-47, Аптечка, 120 патронов 7.62). Предметы перетаскиваются пальцем
  или курсором между любыми ячейками; двойной тап перекладывает в другой инвентарь.
- Справа сверху: [Друзья] - игроки в вашем Wi-Fi, кнопка "+" приглашает.
  У приглашённого справа по центру появляется окно: "Отменить приглашение" / "Принять приглашение".
  Отказ: приглашённый остаётся в своём лобби, пригласивший 5 секунд видит "Игрок ... отменил приглашение".
  Согласие: пригласивший = Host, приглашённый = Client, встаёт слева от Host.
- Рядом с [Друзья] при двух игроках появляется [Выйти]: выйти может любой, оба возвращаются в свои лобби.

Сеть
- UDP 24568: поиск игроков и приглашения. ENet 24567: лобби на двоих.
- Host авторитетен: все действия Client (ник, поворот, снаряжение) уходят Host-у, он их проверяет,
  применяет и рассылает обратно. Позицией Client управляет только Host.
- Для игры: GameState.get_loadout() - ваше снаряжение; Net.roster[id]["loadout"] - снаряжение
  каждого игрока лобби (у Host-а оно известно для всех).

Android
- Export -> Permissions: INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE, CHANGE_WIFI_MULTICAST_STATE.
- Оба устройства в одной сети без AP/client isolation (гостевые Wi-Fi обычно блокируют поиск).
- Статус "В сети" = у устройства есть сетевой (не loopback) IPv4-адрес.

Сохранение: user://profile.json (ник, деньги, оба инвентаря).

Обновление:
- Запрещены операции с неизвестным типом инвентаря.
- Host принимает новое ENet-подключение в состав лобби только в течение окна ожидаемого приглашения.
- Статус «В сети» означает наличие локального IPv4, не проверку доступа в Интернет.
- Игровая сцена раунда не входит в этот ZIP; снаряжение доступно через GameState.get_loadout().
