WiFiLobby — Online Host / Join (прямой ENet/UDP)

1. В лобби нажмите Online. Host выбирает порт (по умолчанию UDP 24567) и нажимает «Создать Online Host».
2. На роутере Host пробросьте UDP 24567 на локальный IP телефона Host. Закрепите за телефоном IP через DHCP reservation.
3. Узнайте публичный IPv4 домашней сети Host. Не путайте его с 192.168.x.x, 10.x.x.x и 172.16-31.x.x.
4. Client нажимает Online, вводит публичный IPv4 Host и тот же UDP-порт, затем Join.
5. Host должен держать игру открытой; Android может приостанавливать приложение в фоне.
6. Если провайдер использует CGNAT, прямой Host/Join не заработает без публичного IP или другого решения (VPN/relay).
7. Оба телефона должны иметь интернет. Локальный поиск друзей по Wi-Fi остался отдельно.
8. Это прототип без авторизации и шифрования приложения: не используйте его для публичных комнат без проверки и защиты RPC.
9. При экспорте Android включите INTERNET permission.
10. Тестируйте из РАЗНЫХ сетей: подключение на публичный IP из той же сети может не работать из-за отсутствия NAT loopback.

Важное ограничение: открытый UDP порт нужен именно на роутере, через который Host подключён к интернету. На мобильном интернете чаще встречается CGNAT.

Публичный IPv4: меню Online показывает адрес через HTTPS api.ipify.org. Нажмите «Обновить публичный IPv4» для повторного запроса. Нужен интернет и Android INTERNET permission. Отображение адреса НЕ означает доступность UDP-порта; для Host необходим проброс порта и отсутствие CGNAT. При использовании VPN сервис может показать адрес VPN.
