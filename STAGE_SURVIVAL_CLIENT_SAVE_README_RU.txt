Выживание: сохранение Client-а на телефоне и загрузка данных на сервер
Как это работает
- Client пишет своё состояние на телефон (user://survival_client_recovery/<id сервера>.json):
  позиция, куда повёрнута камера (yaw/pitch), HP, инвентарь и снаряжение. Отдельный файл на каждый сервер.
  Запись каждые 15 с, при выходе, сворачивании, обрыве связи. Запись идёт через временный файл,
  чтобы сбой не испортил прошлое сохранение. В файле есть номер версии rev.
- Когда Client заходит, Host присылает id своего мира, Client отправляет сохранение ИМЕННО этого сервера.
  Данные с другого сервера Host отвергает (id не совпал).
- Host проверяет данные (числа, размеры, только известные предметы), берёт самую свежую версию
  (по rev: с телефона или копия у Host-а), записывает в сохранение мира, ставит игрока на сервере
  и возвращает ему данные.
- Client применяет полученное сразу, даже если бой уже идёт (раньше применялось только при создании сцены,
  поэтому при входе в уже идущую игру позиция/камера/инвентарь не восстанавливались).
- Если Host сохраняет идущий мир впервые или под новым именем, id мира остаётся прежним,
  и сохранения Client-ов не теряют связь с сервером.
