STAGE 5 — серверное ядро (не готовый Android-сервер)

Добавлены server/simulation_core.gd (фиксированный шаг 20 Гц без графики) и server/persistent_players.gd (постоянные ID и секреты; записи JSON).
Headless сцена инициализирует оба компонента и сохраняет реестр.

НЕ ГОТОВО:
- Клиентские ENet RPC не подключены к новой модели идентичностей.
- Боевая симуляция (стрельба, попадания, инвентарь, коллизии) по-прежнему зависит от battle.gd; новая симуляция только каркас.
- Android Foreground Service не запускает этот Godot headless-процесс; Kotlin-примеры в проекте не интегрированы в APK.
- Не проводились компиляция Godot, Android-сборка и тесты с выключенным экраном.

Следующая работа: перенести серверные RPC из battle.gd в Net/сервер, связать peer_id с UUID через защищённый handshake, реализовать Android Service + native/embedded Godot runtime и проверить на устройстве.
